## Permissions Granted to ACSPI

By running this application, you grant ACSPI permission to:

**File system access**
- Read, create, and manage files within `C:\ACSP`, which is used to store packs, settings, and application data
- Read files you explicitly select through file dialogs (e.g. setting a custom plate)
- Read and write to your Assetto Corsa folder as required for mod management

**System interactions**
- Execute command-line processes to run [Microsoft Texconv](https://docs.microsoft.com/en-us/azure/remote-rendering/resources/tools/tex-conv) for texture conversion (DDS ↔ PNG)
- Create a desktop shortcut for ACSPI upon request
- Open links in your default browser

**Network and data**
- Read your PC name
  - Your PC name and current application version are reported to the ACSPI statistics server on each startup
  - Any runtime errors may be automatically reported to assist with debugging
- Read from and write to the ACSP database
- Upload files to third-party hosting services

---

## Third-Party Services

ACSPI may interact with the following external services:

- **ACSP Database** — used for mod distribution and activation key validation
- **Dropbox** — used to host application updates and version information
- **Imgur** — used by creators to upload mod preview images
- **db4free.net** — hosts the ACSP database

---

## Data Collection

ACSPI collects the following data for statistical and diagnostic purposes:

- Your PC name and application version (reported on startup)
- Error messages from runtime exceptions (reported automatically)

No personally identifiable information beyond your PC name is collected. Data is used solely for maintaining and improving ACSPI.
